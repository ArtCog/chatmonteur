ПРАВИЛА, КОТОРЫЕ НЕЛЬЗЯ НАРУШАТЬ
1. Все кадры здесь — 740 × 416. Для рендера умножать все размеры на 2.595 → 1920 × 1080.
2. Отступы от края не меньше 104px в 1920. Нижние 14% кадра — зона плеера, там ничего.
3. На экране одновременно только один текстовый элемент. Субтитры и акцентная плашка не соседствуют.
4. Одно движение на элемент. Вход — cubic-bezier(.33,1,.68,1), переходы — cubic-bezier(.45,0,.2,1). Линейно только курсор и дрейф.
5. Никаких цветных акцентов в Mono. Цвет разрешён только в баннере канала (14) и в модуле акцентных плашек.
6. Шрифт не заменять ни при каких условиях. Нет Golos Text — скачать, а не подбирать похожий.
7. Код-агент берёт значения из brand-manifest.json рядом с брендбуком: токены, зоны, тайминги, каталог элементов и формат cue-задания. HTML — визуальный референс для человека.
8. Задание на монтаж — cue-список: {t: 84.2, element: "B", text: "это бесплатно", holdSec: 2} — схема и пример в манифесте. Появление точно по слову в озвучке, минимальный интервал между плашками 20с.
9. Вертикальный формат (Shorts 1080×1920): кегли ×1.3, максимум 3 слова на плашке, плашки в полосе y 1150–1500, нижние 420px и правые 180px — UI Shorts, там ничего. Зоны — в манифесте.
Анимация · motion
EASING
Плавно везде: вход — cubic-bezier(.33,1,.68,1), переходы — cubic-bezier(.45,0,.2,1). Линейно — только курсор и дрейф.
ТАЙМИНГИ
Вход 0.5–0.7с · держать дольше (≈70% времени) · выход 0.3–0.4с · между словами/строками 0.16–0.2с.
ПРИЁМЫ
reveal-up · soft-in · draw-line · clip-reveal · wipe / blinds / slab · сборка букв (asm) · drift.
ПРИНЦИПЫ
Одно движение на элемент · синхрон с речью · списки по одному пункту · всё центрируется, ничего не выходит за поля.
