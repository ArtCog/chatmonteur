Акцентная плашка
key-message overlay · hook text
Одна мысль или одно слово внизу кадра. Появляется 5–8 раз за ролик в момент ключевой фразы. Держит внимание, не дублирует речь целиком.
Кинетическая типографика
kinetic typography
Текст, который двигается по словам, заменяется в одной точке или подчёркивается на ходу. Приём для 2–4 слов, не для абзаца.
Хук-плашка
hook / punch-in
Самая громкая разновидность: «БЕСПЛАТНО», «×5 быстрее». Одно-два слова, максимальный кегль, вход со ударом. Не чаще 3 раз за ролик.
Субтитры
captions · это НЕ то же самое
Идут непрерывно, повторяют речь дословно, оформлены нейтрально. Живут в элементе 04 основного брендбука. Смешивать с акцентными плашками нельзя — одновременно на экране только одно.

Что отдать агенту
МАСШТАБ
Кадры здесь показаны в 486px только для просмотра. Агенту нужны размеры для 1920×1080: умножай числа из спек на 2.595. Свой масштаб предпросмотра он выставит сам — передавать его не нужно.
ПОЗИЦИЯ
Базовая линия y 900px из 1080. Полоса допустимого размещения 768–934px. Боковые отступы 104px. Ниже 934px — зона плеера, там ничего.
ТАЙМИНГ
Вход 0.4–0.5с, держать 1.6–2.4с, выход 0.3с. Вторая строка или слово-вывод — с задержкой 0.35с. Появление точно в момент слова в озвучке, не раньше.
ДОЗИРОВКА
5–8 плашек на 10 минут. Хуки с максимальным кеглем (A, E, F, G) — не больше 3 на ролик. Эмодзи только в приёме E, не чаще 2 раз.
ТЕКСТ
Максимум 4 слова в строке, 2 строки. Плашка не повторяет речь дословно — она сжимает мысль до ядра. «Это абсолютно бесплатно» → БЕСПЛАТНО.
КОНФЛИКТЫ
Одновременно на экране только один текстовый элемент. Идут субтитры — акцентная плашка встаёт вместо них. Маркер главы и логобар не мешают, они наверху.
ИЕРАРХИЯ НАБОРА · ЧТО ЯДРО, ЧТО СИТУАТИВНОЕ
ЯДРО · 6 приёмов
B · J · L · O · A · E
Держат ритм всего ролика. B, J, L, O — рабочие лошадки по 2–4 раза. A и E — на два самых сильных момента. Если агент знает только эти шесть, ролик уже выглядит собранным.
СИТУАТИВНЫЕ · 7 приёмов
C · F · H · I · K · N · M
Ставятся только когда в сценарии есть ровно этот повод: цена, цифра, сравнение до/после, переопределение понятия, вопрос перед ответом, реальный риск, закадровый текст. Нет повода — приём не используется.
АРХИВ · 2 приёма
D · G
Не использовать. D дублирует N, G дублирует A и N и ломает плавность системы пружинистым движением. Скрыты за переключателем «showRetired».
АЛГОРИТМ ВЫБОРА ДЛЯ АГЕНТА
1. Найди в расшифровке ключевые фразы — те, что зритель должен унести с собой. На 10 минут их 5–8, не больше.
2. Для каждой определи повод: цена → C, цифра → F, сравнение → H, риск → N, вопрос → K, переопределение → I, закадровый текст → M.
3. Повода нет — бери из ядра: ключевое слово внутри фразы → B, спокойный акцент → J, уточнение → L, «вот главное» → O.
4. Два самых сильных момента ролика отдай A и E. Больше двух хуков максимального кегля не ставить.
5. Проверь: один и тот же приём не идёт дважды подряд, и на экране одновременно только один текстовый элемент.
