# Банк визуала — спецификация для агента-сборщика

Это контейнер, который читает монтажная система (ChatMonteur, `skills/motion.md`).
Собирай СЮДА и ПО ЭТИМ правилам — иначе собранное не подключится к монтажу.

Дом банка — в репозитории ChatMonteur, но **содержимое в git не попадает** (`.gitignore`:
тяжёлые файлы + чужие no-copyright ролики нельзя публиковать в MIT-репо). Коммитится
только эта спецификация.

## Структура папок

```
bank/
├── BANK.md          ← этот файл (единственное, что в git)
├── ledger.jsonl     ← реестр: одна строка JSON на каждый файл (см. ниже)
├── gameplay\        ← фоновый геймплей (no-copyright!), 3-5 разных игр, куски 2-5 мин
├── thematic\        ← тематический движ: бегущий терминал, агент печатает код,
│                      таймлапсы, UI инструментов в движении (свои записи)
├── illustrations\   ← AI-иллюстрации и метафоры (фиксировать style-prompt в ledger)
├── screenshots\     ← скриншоты реальных вещей: сайты, твиты, посты, интерфейсы
└── music\           ← безвокальные инструментальные подложки + SFX (whoosh, click)
```

## ledger.jsonl — реестр (ОБЯЗАТЕЛЕН для каждого файла)

Одна строка на файл, поля:

```json
{"file": "gameplay/mario-kart-01.mp4",
 "kind": "gameplay",
 "tier": "plain",
 "priority": 3,
 "what": "Mario Kart 8, трасса Rainbow Road, от третьего лица",
 "source": "https://youtube.com/... (или 'own recording' / 'generated')",
 "license": "no-copyright заявлен автором / CC0 / own / CC-BY (автор)",
 "attribution_required": false,
 "style_prompt": "только для illustrations — полный промпт, чтобы стиль был воспроизводим",
 "added": "2026-07-31",
 "used_in": []}
```

### tier и priority — как Артур сортирует фоны (2026-08-04)

- **`tier`** — две секции, введены после отбора фонов на живых кадрах:
  - `serious` — «чуть более серьёзный фон». Абстрактная геометрия, ретро-эстетика,
    космос: смотрится сдержанно и не выглядит как детская игра.
  - `plain` — обычный фон. Гонки, аркада, всё яркое и бытовое.
- **`priority`** — 1 = брать первым. Порядок задаёт Артур и **меняет его когда захочет**;
  агент не переставляет приоритеты сам и не спорит с ними. На 2026-08-04:
  геометрия → ретро-шутер → гонки → космос.

Ни то, ни другое не выводится из файла — это вкус владельца канала. Поэтому у нового
файла оба поля заполняются **с его слов**, а не догадкой.

## Жёсткие правила

1. **Файл без строки в ledger не существует** для монтажа. Сначала строка, потом файл.
2. **Лицензия — не догадка.** «no-copyright» — только если автор ролика это явно заявил
   (описание/канал). Сомнение = не брать. CC-BY = заполнить автора, указывать в описании ролика.
3. **`used_in` ведёт монтажная система** — при использовании ассета в ролике туда пишется slug.
   Правило канала: похожие кадры не повторяются между роликами — перед выбором смотреть это поле.
4. **Геймплей**: куски по 2–5 минут, БЕЗ HUD-музыки/звука (или звук будет отрезан), 1080p+,
   30fps+. Спокойные секции — фон не должен воровать внимание у голоса.
   - **Только реальная игра, не трейлер** (Артур 2026-08-04): «нам не нужны трейлеры,
     нам нужна именно игра от первого лица или от третьего лица, когда человек играет
     сам». Смонтированный ролик издателя выдаёт себя склейками и рекламными планами.
   - **Резать до того, как кончился игровой процесс.** Экран результатов, меню,
     таблица очков — это уже не фон. Смотреть конец куска глазами перед укладкой.
   - **Потолок битрейта — 30 Мбит/с.** Выше не нужно: финальный рендер канала идёт
     на 24 Мбит/с, а 100-мегабитный мастер просто не проигрывается в просмотре.
     Ставить `-crf 20 -maxrate 30M -bufsize 60M`, а не гнаться за CRF 12.
   - **Никогда не растягивать вверх** и не форсировать 30 к/с на исходнике 29,97 —
     первое даёт мыло, второе дублирует кадры и читается как подёргивание.
5. **Тематический движ**: свои записи экрана; без пауз и мёртвых мест внутри куска;
   тёмная тема (правило «затемни то, что не главное»).
6. **Иллюстрации**: style-prompt в ledger обязателен — консистентность стиля между
   картинками одного ролика важнее красоты отдельной картинки.
7. **Музыка**: только инструментал без вокала; в ledger писать BPM и настроение
   (`"what": "спокойный лоу-фай, 82 BPM, без нарастаний"`).

## Что НЕ сюда

- Ассеты одного конкретного ролика (живут в `projects/<имя>/assets/` его проекта).
- Бренд-компоненты и шрифты (живут в `assets/brand/` / реестре HyperFrames).
- Всё, у чего нет права на использование.
