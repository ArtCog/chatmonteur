# CONTEXT.md — domain glossary

The vocabulary this project actually uses. When naming things (issues, commits,
functions, hypotheses), use these terms as defined — don't drift to synonyms.
Decisions behind them live in `docs/adr/`.

## Pipeline & cutting

- **capability** — one mechanical operation, implemented as a module in
  `chatmonteur/tools/` exposing `TOOL`. Discovered at runtime by the registry;
  `chatmonteur tools` lists them. 16 exist today.
- **pipeline** — a YAML in `pipelines/` sequencing capabilities. The default is
  `talking_head`: normalize → cut_silence → transcribe → color → subtitles → render.
- **Tier 1 cut** (тупая резка) — pause removal by AUDIO LEVEL only (`cut_silence`,
  auto-editor). Never touches meaning; silent demos are protected by level, not words.
- **Tier 2 cut** (умная резка) — meaning-based: the AGENT reads the word-level
  transcript, tags fillers/false starts/retakes, writes an EDL, gets approval.
  No script auto-decides this (ADR-0011).
- **Branch A / Branch B** (ветка А/Б) — which audio drives Tier 1. A: the mixed
  track, level-prepared first, threshold 0.14 of peak. B: the separate voice-only
  OBS track against the RAW file, threshold 0.06 — locked by real-footage testing.
- **EDL** — `transcripts/edl.json`, `{"removed": [[start, end], …]}`. Executed by
  the `cut_edl` capability in ONE frame-accurate ffmpeg pass.
- **master.json** — the word-level transcript (`transcripts/master.json`), the
  agent's working surface for Tier 2 and captions.
- **checkpoint** — `.chatmonteur/checkpoint.json`; re-running a pipeline resumes
  instead of recomputing.

## Visual pass

- **storyboard** — the ONE artifact planning the whole visual pass
  (`transcripts/storyboard.json`, sections `zooms` / `overlays` / `inserts`),
  burned in that order by the `storyboard` capability after approval.
- **cue** — one on-screen brand event (plashka, callout, transition) in the
  brandbook's cueFormat; `cues.py` enforces the budget gate (one on screen,
  spacing, per-10-min caps).
- **plan gate** — `storyboard`'s plan review: rejects a visual plan that would
  read as "he just cut the pauses" (dead stretches, text overload, repeated zooms).
- **file gate** — `qc`, the last pipeline step: blocks delivery of a broken
  render (black frames, silent/clipped audio, duration drift). Never bypassed.

## Brand

- **card** (карточка) — one numbered drawing in the designer's brandbook decks
  (`assets/brand/default/source/*.dc.html`).
- **component** — the HyperFrames port of a card
  (`assets/brand/default/components/<name>/`), rendered with alpha.
- **catalog** — `catalog.json`, generated by `build_catalog.py`: the full card
  inventory with statuses `ready · dropped · deferred · archived · todo`.
  Look here BEFORE building any on-screen graphic (rule zero).
- **scrim** — the dark plate under captions, `rgba(8,9,10,.52)` (card 04).
- **HyperFrames** — the HTML/GSAP motion engine rendering all brand graphics
  (ADR-0008). Its registry is checked before writing any new graphic code.

## Process

- **dogfood** — editing a REAL video of the founding channel through the product,
  raw footage to publishable render. The hard gate for "done" (ADR-0003).
- **rule zero** — the agent does not invent: check the HyperFrames catalog and
  every dependency's own `--help` before writing code (see `CLAUDE.md`).

## Terms we avoid

- **cut_meaning** — a deleted tool (naive filler-dictionary cutter). Meaning
  cuts are Tier 2 agent work; don't reintroduce an auto-detector for them.
- **"cinematic" / mood adjectives in plans** — name the concrete visual/audio
  cause instead (the storyboard gate can't score vibes).
